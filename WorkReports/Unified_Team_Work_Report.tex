  \item Implemented role-based routing architecture with Next.js Route Groups (\texttt{(public)}, \texttt{(dashboard)/admin}, \texttt{(dashboard)/nodal-officer}) and dynamic sidebar layout navigation.
  \item Conducted technical reviews of contributor pull requests: Lokesh's caching API (\texttt{9ff3246}), Yash's cache security and upload form (\texttt{fa507b8}), and Krishna's 32-file access management branch (\texttt{a52adde}).
  \item Executed cross-module integration testing and negative upload validation.
  \item Merged Pull Request \#1 (\texttt{5466559}) on 14 October 2026, executing milestone branch reconciliation and integrating 47 files (+10,506 / $-$808 lines) combining Krishna's access architecture and Yash's cache security into \texttt{main}.
  \end{itemize}

\item \textbf{Krishna (12.0 Hours) -- Access Management, Organogram Hierarchy \& Workflow Dispatch:}
  \begin{itemize}[leftmargin=1.2em, itemsep=1.5pt]
  \item Modeled the typed Institute Organogram hierarchy in \texttt{src/lib/organogram.ts} (577 lines, 56 distinct institutional units across 5 tiers) and created the searchable/selectable tree component (\texttt{OrgTree.tsx}, 300 lines).
  \item Built the NIRF Data Catalogue (\texttt{data-catalogue.ts}, 320 lines) mapping 28 requestable metrics to custodial units.
  \item Developed the 3-step administrative Data Request Composer (\texttt{admin/data-requests/new/page.tsx}, 730 lines) with per-section metric narrowing, live recipient resolution, and simulated outbox email previews.
  \item Engineered zero-trust tokenized access provisioning (\texttt{access.ts}, \texttt{dispatch.ts}): SHA-256 hashed single-section upload grants with automatic expiration, link rotation on reminders, and automatic revocation.
  \item Created the restricted upload portal (\texttt{portal/[token]/page.tsx}, \texttt{PortalUploader.tsx}) with server-side mime validation, file size enforcement (25 MB), and checksum audit logging.
  \end{itemize}

\item \textbf{Yash Sharma (8.00 Hours) -- Cache Security, Scraper Hardening \& Nodal Upload UI:}
  \begin{itemize}[leftmargin=1.2em, itemsep=1.5pt]
  \item Hardened the Next.js cache revalidation endpoint (\texttt{/api/revalidate}) with shared-secret authorization (\texttt{REVALIDATION\_SECRET}) and updated the Python scraper callback in \texttt{app.py} to inject the secret.
  \item Built the departmental Nodal Officer Submission form (\texttt{nodal-officer/submissions/new/page.tsx}, +324 / $-$188 lines) with metric category selectors, tabular raw data file upload, proof document upload, and maker-checker \texttt{PENDING} status feedback.
  \item Resolved merge conflicts in \texttt{package-lock.json} to preserve Next.js 15 React DOM typings, purged committed Python bytecode, and updated \texttt{.gitignore}.
  \end{itemize}

\item \textbf{Lokesh (7.0 Hours) -- NIRF Ingestion, Caching API \& Organogram Baseline:}
  \begin{itemize}[leftmargin=1.2em, itemsep=1.5pt]

  \item Structured and generated 6 benchmark JSON ranking datasets for 2024 and 2025 across Engineering, Innovation, and Overall categories (3,530 lines).
  \item Authored the initial Institute Organogram architectural diagram in Mermaid flowchart format (\texttt{Institute\_Organogram.md}, 113 lines) establishing the executive, deanship, and school hierarchy.
  \item Authored the three-layer caching integration guide (\texttt{Integration\_Docs.md}, 60 lines).
